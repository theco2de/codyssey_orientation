# 두 AI에 전달한 요청문

두 AI에 아래 요청과 `2-1/기획서.md`를 똑같이 전달합니다. 한쪽에만 추가 요청을 하지 않습니다.

- 기획서 확정본: `2-1/기획서.md` (156줄, SHA-256 앞 12자리 `1fde20d2c9e3`)

## 요청문

```text
첨부한 기획서.md대로 HTML 페이지를 만들어 줘.
- HTML 파일 1개로 만들고, CSS와 JavaScript는 같은 파일에 넣어 줘.
- 기획서의 '추가 기능'은 만들지 말고 '완료 기준'이 모두 맞아야 해.
- 로그인, 서버, API 키, 외부 파일 없이 브라우저에서 열려야 해.
- 화면 문구는 한국어로 써 줘.
- 수정한 HTML 전체를 줘.
```

## 전달 방법

1. AI 채팅에 `2-1/기획서.md` 내용을 붙여 넣거나 파일로 첨부합니다.
2. 위 요청문을 그대로 붙여 넣습니다.
3. 받은 HTML 전체를 `2-2/평가알리미_AI2_모델이름.html`로 저장합니다.
4. 사용한 서비스와 모델 이름을 `제작검증기록.md`에 적습니다.
